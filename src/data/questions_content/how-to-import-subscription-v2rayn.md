## v2rayN 订阅导入指南
v2rayN 是 Windows 平台上老牌且轻量级的开源代理工具。

### 添加订阅服务器
1. 复制 v2ray 格式的订阅链接。
2. 打开 v2rayN 主界面，点击顶部菜单栏的“订阅” -> “订阅设置”。
3. 点击“添加”，在地址（url）处粘贴链接，备注填入服务商名称，点击确定保存。

### 更新与开启系统代理
1. 回到主界面，点击“订阅” -> “更新订阅（不通过代理）”。此时下方列表会刷出大量节点。
2. 选中一个节点，按回车键设为活动服务器。
3. 在屏幕右下角任务栏找到 v2rayN 的小图标，右键点击，在“系统代理”菜单中选择“自动配置系统代理”即可上网。
