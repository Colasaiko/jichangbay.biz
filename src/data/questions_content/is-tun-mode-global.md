很多人在设置代理软件（如 Clash、Sing-box）时，会把“TUN 模式”和“全局模式（Global）”混淆。这里明确一个结论：**TUN 模式不是全局模式**。

### 什么是模式（路由策略 vs 流量接管）

要理解它们的区别，你需要知道代理软件工作时的两个独立步骤：

#### 1. 流量怎么进入代理软件？（接管方式）
- **System Proxy（系统代理）**：软件在你的系统中登记一个端口，浏览器乖乖把流量送过来。但有些软件（如终端命令行、某些游戏）不听话，不走这个端口。
- **TUN 模式**：软件在系统底层创建一张“虚拟网卡”。所有软件发出的网络请求，只要往外发，就会被这张网卡强制拦截并送入代理软件。这解决的是“流量漏网”的问题。

#### 2. 流量进入后怎么处理？（路由策略）
- **规则模式（Rule）**：进入代理的流量，会经过配置文件里的规则匹配。匹配到国内域名的，直连（不翻墙）；匹配到国外域名的，走节点（翻墙）。
- **全局模式（Global）**：进入代理的流量，不管三七二十一，全部走节点发到国外。

### 核心结论
**TUN 和规则模式是完全可以同时开启的。**
当你同时开启 TUN 和 规则模式时，发生的事情是：
所有软件的流量都被虚拟网卡强制抓取进 Clash，然后 Clash 按照规则，把国内流量放行，把国外流量加密发往节点。
这才是很多高阶用户最推荐的日常状态，它既保证了代理无死角，又不会浪费机场流量。

### 什么时候需要 TUN 模式？
如果你只用浏览器看看网页，传统的“系统代理 + 规则模式”就足够了，不必开启 TUN。
但在以下情况，你必须使用 TUN：
- 玩外服游戏，需要代理游戏客户端。
- 使用终端（Terminal、CMD）下载 GitHub 代码。
- 使用某些坚决不遵守系统代理设置的应用（如部分 UWP 商店应用、老旧的桌面端软件）。

如果你开启 TUN 后发现无法上网（[Clash开启TUN后全部Timeout](/questions/clash-all-nodes-timeout/)），请检查是否与其他加速器发生了网卡冲突。
