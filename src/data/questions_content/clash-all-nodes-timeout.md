当你打开 Clash，测速发现所有节点都显示 `Timeout`，或者“代理有流量但是连不上”，这通常意味着你的本地客户端与机场节点服务器之间的通信被阻断了。以下是完整的排查步骤，按顺序检查即可解决大部分超时问题。

### 1. 确认基础状态：机场是否正常
不要急着重置配置，先确认：
- **套餐是否到期**？流量是否已经耗尽？登录机场官网后台查看数据用量。
- **订阅是否过期**？在 Clash 的“订阅/配置”页面，点击刷新或更新订阅，看是否能拉取到最新节点。如果更新订阅本身也报 Timeout，说明连官网域名都被墙了。
- **服务商状态**：留意机场电报群或公告面板，判断是否遇到不可抗力的网络封锁或遭受 DDoS 攻击导致的“全节点故障”。

### 2. 本地网络与防火墙阻断
如果你使用的是 **校园网** 或公司内网，“校园网连接节点超时”是非常常见的。
许多内网防火墙会封锁非标准的端口，或者基于流量特征掐断了代理协议的握手。
- 尝试切换到手机热点，再次测速。如果手机热点下有延迟且能上网，说明当前网络对机场协议有限制（校园网限制）。
- 若确实是校园网问题，请向机场客服询问是否支持 443 端口接入，或尝试开启伪装功能。

### 3. Clash 开启 TUN 后全部 Timeout
如果你在开启 TUN 模式后，原本正常的节点瞬间全部 Timeout 且无法上网，通常是 **DNS 冲突** 或底层路由表写入失败。
- **表现**：“代理有流量但是连不上”，且国内网站也打不开。
- **解决**：在 Clash Verge 中关闭 TUN，先恢复系统代理。然后在设置中检查是否安装了 Service / Helper 模式，重装该服务。另外检查电脑上是否有其他的加速器、VPN 正在后台运行，它们会和 TUN 抢夺虚拟网卡权限。

### 4. 系统时钟误差
这是一个容易被忽略的细节。绝大部分科学上网协议（如 Vmess, Trojan）要求你的电脑时间与标准时间的误差不能超过 1 分钟。
如果你的系统时间不准（比如快或慢了 5 分钟），即使节点正常，服务器也会拒绝连接，表现为“所有节点全部超时”。请前往系统设置，开启“自动同步时间”。

### 5. 电脑用着用着突然全部 Timeout
“clash windows 突然连不上”，可能是：
1. **IP 被临时封禁**：你短时间内发起了过多连接，节点防火墙把你拉黑了，切换节点即可。
2. **连接池耗尽**：系统后台残留了太多死连接。尝试重启电脑或重启路由。
3. **软件崩溃**：内核崩溃导致连接假死，重启客户端。

排查完毕后，仍然无解的，建议重新下载最新的 [Clash Verge](/clients/clash-verge/)，并确保配置不是从两年前旧版软件中直接拷贝过来的。
