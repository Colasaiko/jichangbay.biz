## Clash 导入失败原因及解决
在 Clash (Verge / Mihomo) 中粘贴订阅链接点击下载时，有时会提示 Network Error 或 Timeout。

### 常见原因
1. **系统代理卡死**：当前开启了失效的代理，导致连下载配置的请求都被阻断。
2. **DNS 污染**：本地网络无法解析订阅域名的真实 IP。

### 解决步骤
- 首先，**关闭 Clash 的系统代理（System Proxy）和 TUN 模式**。
- 其次，如果直连依然下载失败，说明该订阅域名在你的网络环境下被屏蔽。请登录机场官网，通常会提供备用的订阅下载地址，复制备用地址重新导入。
- 最后，如果所有备用地址都失效，请联系客服获取最新的防封锁链接。
