## 奇怪的现象：延迟正常，网页加载失败
在 Clash 界面点击测速，所有节点都是绿色的，说明节点存活且连接完全正常。但是网页一直转圈打不开，最终提示 `ERR_CONNECTION_TIMED_OUT`。
既然节点没坏，问题一定出在**本地流量如何交接给 Clash**的环节上。

## 本地排查点

### 1. 系统代理（System Proxy）未真正生效
你可能只在 Clash 中选中了节点，却忘了打开系统的总开关。
- **检查**：在 Clash Verge 界面中，确认 `System Proxy` 处于开启状态。
- **验证**：打开 Windows 设置 -> 网络和 Internet -> 代理，查看“使用代理服务器”是否被自动开启，且地址指向 127.0.0.1，端口 7890。

### 2. 浏览器插件冲突（如 SwitchyOmega）
在 Chrome 中安装了 Proxy SwitchyOmega 等插件，它会拥有比 Windows 系统设置更高的优先级。
- 如果插件设置了错误的端口（比如之前用 v2rayN 的 1080）。
- **解决**：将浏览器插件设置为“系统代理”或者直接禁用。

### 3. DNS 污染与解析循环
在 `Rule（规则）`模式下，如果 Clash 的 DNS 设置异常，会导致请求在本地无限循环。
- 尝试将 Clash 的工作模式从 `Rule` 切换为 `Global（全局）`。
- 如果全局模式能上网，规则模式不能，说明是 Clash 配置内的分流规则出现了问题，请更新订阅。

### 4. TUN 模式虚拟网卡接管失败
- 如果你的权限不够，TUN 网卡创建失败，但界面显示开启。这会导致所有网络请求进入黑洞。
- **解决**：右键 Clash 图标选择“以管理员身份运行”，然后重新开启 TUN 模式。

### 5. 电脑安全软件拦截
某些杀毒软件会识别 Clash 劫持系统流量的行为并拦截。
- **解决**：将 `mihomo.exe` 加入白名单。
