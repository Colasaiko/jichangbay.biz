## 快速判断
一个节点超时通常是服务器问题；但**所有节点同时超时**，几乎一定是你自身账号或系统环境出现了问题。

## 最常见的 5 大原因与按序排查指南

### 1. 账号套餐到期或流量耗尽（最容易被忽略）
很多用户开启了后台自动运行代理，某天突然发现网页打不开，折腾了半天客户端，最后才发现是套餐到期了。
**排查动作：**
- 关闭本地代理开关（设为直连）。
- 浏览器登录机场官网。
- 检查“仪表盘”或“我的套餐”，确认当前日期在有效期内，且剩余可用流量 > 0。

### 2. 旧订阅配置已失效
机场为了应对防火墙的封锁，会不定期更换入口 IP 和端口。如果你的客户端还在拿着半个月前的旧配置去连接，自然全军覆没。
**排查动作：**
- 确保关闭了系统代理（防止旧节点阻断请求）。
- 在客户端中找到“更新订阅（Update）”按钮并点击。
- 如果提示网络错误无法更新，请回到机场官网，复制最新的**备用订阅链接**，在客户端中覆盖原链接后重新下载。

### 3. 系统时间偏差导致 TLS 握手失败
无论是 vmess、trojan 还是 vless，其底层的安全加密协议对时间极其敏感。如果你的设备系统时间与国际标准时间相差超过 2 分钟，服务器将直接拒绝连接。
**排查动作：**
- Windows：右键右下角时间 -> 调整日期/时间 -> 开启“自动设置时间” -> 点击“立即同步”。
- macOS：系统设置 -> 通用 -> 日期与时间 -> 打开“自动设置日期和时间”。

### 4. 本地 DNS 污染或路由卡死
有时候客户端里的节点甚至能测出延迟，但就是打不开网页，这属于典型的 DNS 或路由劫持。
**排查动作：**
- 清理 DNS 缓存：在 Windows 命令行执行 `ipconfig /flushdns`。
- 重启路由器和电脑光猫。
- 尝试切换到手机 4G/5G 热点进行交叉测试。如果热点能连而 Wi-Fi 不能连，说明是宽带运营商在阻断。

### 5. 多个代理软件冲突
同时安装了 Clash、v2rayN 以及各种浏览器代理插件（如 SwitchyOmega）。多个软件争夺系统的 1080 端口或路由表，导致流量死循环。
**排查动作：**
- 彻底退出所有其他代理软件，仅保留一个主力客户端。
- 检查浏览器是否配置了异常的代理扩展并将其禁用。

## 最后仍然不能解决怎么办？
如果你完成了上述步骤依然全红，请带上你的客户端报错日志，发送工单联系机场客服。如果官网也失联超过 48 小时，准备更换备用机场。
