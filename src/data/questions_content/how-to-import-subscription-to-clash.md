## Clash 电脑端导入教程
无论是 Windows 还是 Mac，Clash Verge 等衍生版本都是最强大的桌面代理工具。

### 导入步骤
1. 在服务商后台复制“Clash 订阅链接”。
2. 打开 Clash 客户端，找到左侧菜单的“订阅（Profiles）”或“配置”。
3. 在输入框粘贴链接，点击“导入”或“Download”。
4. 下载完成后，列表中会出现一个新的配置块。**单击选中它**（确保它亮起或处于激活状态）。

### 开启代理
切换到“设置（Settings）”或“通用”页面，找到“系统代理（System Proxy）”并打开。此时电脑的浏览器流量就会被接管，你可以尝试访问 Google 验证是否成功。
