## 机场使用全流程
购买机场后，你需要进行一系列设置。其实步骤很简单：**购买 -> 复制订阅 -> 导入客户端 -> 开启代理**。

### 1. 购买与获取订阅
在服务商官网注册并购买套餐后，通常在“仪表盘”或“我的订阅”页面能看到一键订阅按钮或长串的 URL 链接。

### 2. 选择合适的客户端
- Windows：推荐 Clash Verge 或 v2rayN。
- macOS：推荐 Clash Verge 或 Surge。
- iOS：推荐 Shadowrocket 或 Quantumult X。
- Android：推荐 v2rayNG 或 Clash for Android。

### 3. 导入与运行
在客户端内找到“配置”或“订阅”选项，粘贴链接并更新。随后在主界面选择一个延迟较低的节点，打开总开关即可畅游网络。
